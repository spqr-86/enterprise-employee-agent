# 0001 — Evidence granularity for v0.1 (no sub-document chunking)

Status: accepted (2026-09-13)
Related: Issue #7 (micro-eval dataset), `data/manifest.json` (`chunking_version: none-v1`)

## Decision

For v0.1, acceptable-evidence IDs in eval cases are whole-document IDs (the `documents[].id`
values in `data/manifest.json`), not sub-document fragments. Recall@k and groundedness are
scored as "cited the correct document(s)," not "cited the correct paragraph."

## Why

The corpus currently holds two whole documents with no chunking. Building fragment-level
chunking (boundaries, IDs, re-validating existing draft cases against them) is extra work not
needed to get a first working scorer running against the already-built Issue #6 workflow logic
(8 of the 14 draft cases in `evals/cases/draft-v0.1-micro-eval.md` don't need retrieval at all).

## Consequence

- Issue #7's acceptance criterion "identifies all acceptable supporting fragment IDs" is
  satisfied by document IDs at the current `chunking_version: none-v1`.
- If/when sub-document chunking is introduced, this decision must be revisited: existing cases'
  evidence IDs will need updating from document-level to fragment-level, and Recall@k results
  before/after are not comparable.
